## Experience

### Software Engineering Intern, Lexon IT · Aug 2026 to Nov 2026

Owned the build and release of **AutoHirU**, a platform that automates the repetitive part of job hunting, from the first commit to a live production deployment.

- **Auto Apply engine and Chrome extension:** discovers matching jobs, fills application forms from the student's profile and resume, and tracks every application. Large-company (Workday) career sites get a guided flow that fills the form and hands the final step to the user.
- **Resume tools:** tailor a resume to a pasted job description, with missing keywords, suggested edits, and accept or reject on each change.
- **Company-reply alerts:** Gmail sync that tells students when an employer responds.
- **Growth and operations:** referral program with rewards and apply-limit bonuses, an admin console with its own secure accounts, a super admin portal with an ads studio and a maintenance switch.
- **Platform:** Next.js frontend with a consistent design system (light and dark mode, mobile-first), a hosted API with PostgreSQL, Clerk authentication, and a repeatable release pipeline for the extension.
